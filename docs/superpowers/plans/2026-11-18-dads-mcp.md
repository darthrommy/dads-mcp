# dads-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** デジタル庁デザインシステム（DADS）のガイドライン・コンポーネントコード・デザイントークンを手元にスナップショット保存し、MCP ツールで AI に返す非公式 MCP サーバーを作る。

**Architecture:** `update` がサイト（sitemap → 各ページ HTML → Markdown）、GitHub の 2 リポジトリ（tarball）、npm のトークンを取得し、キャッシュディレクトリに保存する。MCP サーバーはスナップショットをメモリに読み込み、7 つのツールで出典付きの Markdown を返す。スナップショットがなければ起動時にバックグラウンドで取得する。

**Tech Stack:** TypeScript 5.9 / Node.js >= 20 / ESM、`@modelcontextprotocol/sdk` 1.x（`McpServer` + `StdioServerTransport`）、`zod`、`cheerio`、`turndown` + `turndown-plugin-gfm`、`tar`（node-tar 7）、`vitest`。

**Spec:** `docs/superpowers/specs/2026-11-18-dads-mcp-design.md`

## Global Constraints

- Node.js 20 以上で動くこと（`engines.node: ">=20"`）。Node 22 以降にしかない API（`fs.glob` など）は使わない。macOS / Linux / Windows で動くこと（パスは必ず `node:path` で組み立てる）
- 配布は GitHub から直接：`npx -y github:darthrommy/dads-mcp`。ビルド成果物（`dist/`）はコミットしない。`prepare` スクリプトでビルドする
- package.json: `"name": "dads-mcp"`, `"type": "module"`, `"bin": { "dads-mcp": "dist/cli.js" }`, `"license": "MIT"`, `"repository": "github:darthrommy/dads-mcp"`
- User-Agent: `dads-mcp/<package.json の version> (+https://github.com/darthrommy/dads-mcp)`。個人情報を入れない
- 同時接続数は 4 まで
- ガイドライン本文、デジタル庁のコンポーネントコード、トークンをリポジトリに入れない。テストのフィクスチャは架空の文章で手書きする
- MCP サーバー実行中は stdout に JSON-RPC 以外を書かない。ログはすべて stderr
- サイト出典の書式（そのまま）:
  ```
  出典: 「<ページタイトル>」（デジタル庁デザインシステム）<URL> を dads-mcp が取得・整形
  ```
- GitHub 出典の書式: `出典: digital-go-jp/<repo>（MIT License）<ファイルの GitHub URL> commit <SHA 先頭7桁>`。SHA がなければ ` commit ...` を省き、URL は `main` を使う
- トークン出典の書式: `出典: @digital-go-jp/design-tokens v<version>（MIT License）`
- 出典行の後に 1 行 `取得日: YYYY-MM-DD`（`manifest.fetchedAt` の先頭 10 文字）
- 返答本文が 20000 文字を超えたら 20000 文字で切る
- スナップショットが 30 日より古ければ返答末尾に更新を勧める一文を付ける。自動更新はしない
- 初回取得中は最大 60 秒待つ
- ページ変換失敗が全体の 2 割以上なら更新を中止し、既存スナップショットを残す
- 更新コマンドの案内文はすべて `npx -y github:darthrommy/dads-mcp update`

## Review Focus

1. サーバーのバックグラウンド初回取得と CLI の `update`（または 2 つのクライアントの同時起動）が重なる → 後から来た方は「別の更新が実行中」で止まり、スナップショットは壊れない（Task 8 の `rejects a second concurrent update via lock file`）
2. 名前の表記ゆれ（`Button` / `button` / `ボタン` / `ボタン（概要）` / 全角 `ＢＵＴＴＯＮ` / React 名 `Breadcrumbs`）→ 同じコンポーネントに解決される（Task 9 の `resolves component names across notations`）
3. 既存スナップショットがある状態で `update` 中にネットワークが落ちる → 既存は残り、サーバーはオフラインでもそれで答える（Task 8 の `keeps existing snapshot when network fails`）
4. 古い版の dads-mcp が書いたスナップショット（`schemaVersion` 違い）や途中で壊れたキャッシュ → クラッシュせず「スナップショットなし」として扱い、取り直す（Task 9 の `treats mismatched schema or corrupt cache as absent`）
5. stdout へのログ混入で stdio プロトコルが壊れる → 実プロセスを MCP クライアントで起動してツールが呼べる（Task 10 の e2e テスト）

## Shared Types（Task 1 で `src/types.ts` に作る。以降のタスクはこれを使う）

```ts
export interface PageDoc {
  path: string;          // "components/button/usage"。トップページは "index"
  url: string;           // 絶対 URL（末尾スラッシュあり）
  title: string;         // <title> から「｜デジタル庁デザインシステムβ版」を除いたもの。例 "ボタン（概要）"
  updated?: string;      // "2026-10-21"
  markdown: string;      // "# <title>\n\n" から始まる本文
  resourceLinks: { html?: string; react?: string }; // 各種リソース表から取ったリポジトリ内ディレクトリ名
}
export type RepoKind = "html" | "react";
export interface ComponentFile { path: string; content: string } // コンポーネントディレクトリからの相対パス（"/" 区切り）
export interface RepoComponent { dir: string; files: ComponentFile[] }
export interface RepoSnapshot { kind: RepoKind; sha?: string; components: RepoComponent[] }
export interface ComponentEntry {
  slug: string; nameJa: string; summary: string;
  htmlDir?: string; reactDir?: string;
  pages: { overview?: string; usage?: string; accessibility?: string }; // PageDoc.path
}
export interface TokenSnapshot { version: string; css: string; simpleCss: string; json: Record<string, unknown> }
export interface Manifest {
  schemaVersion: 1; fetchedAt: string; // ISO 8601
  repos: { html?: string; react?: string }; tokensVersion: string;
  counts: { pages: number; components: number }; warnings: string[];
}
export const SCHEMA_VERSION = 1;
```
